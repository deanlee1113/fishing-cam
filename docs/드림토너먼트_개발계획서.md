# 드림토너먼트 선수용 페이지 개발계획서 (v1.0)

> 본 문서는 개발자에게 전달하기 위한 1차 개발계획서입니다. "개발자 위임 사항(10장)"에 명시된 항목은 개발자가 합리적 방안을 제안하면 운영팀이 검토·확정합니다.

---

## 1. 개요
드림토너먼트(오프라인 + 온라인 계측 대회) 참가 선수가 어획 증거영상을 업로드하고, 관리자가 검수한 영상을 **낚시의맛 앱 회원**에게 공개하는 웹 페이지.

## 2. 사용자 역할
| 역할 | 인증 방식 | 권한 |
|---|---|---|
| 일반 비회원 | 인증 없음 | 접근 제한 (안내 페이지만 노출) |
| 낚시의맛 앱 회원 | 휴대폰 번호 입력 → 낚맛 API 조회, 세션 유지 | 명예의 전당 + 승인된 영상 시청, 전체 공개 공지 열람 |
| 드림토너먼트 선수 | 아이디 + 비밀번호 로그인 | 본인 회차별 영상 업로드, 계정 정보 변경, 운영진과 1:1 메시지 |
| 관리자 | 별도 관리자 로그인 | 영상 검수, 선수 계정 관리, 순위 관리, 공지 작성, 선수와 1:1 메시지 |

## 3. 인증 / 계정

### 3-1. 선수 로그인
- **초기 계정 (운영진 사전 등록)**
  - 아이디: `이름 + 선수번호` 형식 (예: `홍길동012`) — 동명이인 충돌 방지
  - 비밀번호: 휴대폰 번호 뒷 4자리
- 첫 로그인 후 마이페이지에서 아이디/비밀번호 변경 가능

### 3-2. 낚시의맛 앱 회원 인증 (시청용)
- 사이트 진입 시 **휴대폰 번호 입력** 요구
- 입력된 번호를 **낚시의맛 팀 제공 API**로 조회 → 회원 확인 시 열람 가능
- 한 번 인증 후 **세션 유지** (만료 기간은 개발자 제안 후 확정)
- 미회원 시: "낚시의맛 앱 가입 후 이용 가능합니다" 안내

### 3-3. 관리자
- 별도 관리자 계정 (소수)

## 4. 화면 구성

### 4-1. 낚맛 회원 영역 (휴대폰 번호 인증 후, 비로그인 시청자)
- **메인 / 명예의 전당**
  - 회차 탭: `1전 | 2전 | 3전 | 결승` (현재는 1전만 활성)
  - 회차별 순위 리스트
  - 선수 카드 클릭 → 해당 선수의 **승인된 어획 영상** 모아보기
- 상단: 전체 공개 공지사항

### 4-2. 선수 영역 (아이디/비번 로그인 후)
- **대시보드**: 선수 전용 공지 + 알림(공지/메시지)
- **마이페이지**: 아이디/비밀번호 변경
- **업로드 페이지**
  - 회차 탭: `1전 | 2전 | 3전 | 결승`
  - 회차 카드 클릭 → 업로드 화면
  - **상단 주의 문구 (강조 표시)**

    > ⚠ 캐스팅 → 훅셋 → 랜딩 → 계측까지 모두 담긴 **원본 영상**만 업로드 가능합니다. **편집된 영상은 반려됩니다.**

  - 파일 선택 + 업로드 버튼
  - 마릿수만큼 추가 업로드 가능 (예: 3마리 → 영상 3개)
  - 본인 업로드 목록 + 상태(`검수 대기 / 승인 / 반려(사유)`)
  - **검수 대기 상태**: 선수가 직접 삭제·재업로드 가능
  - **승인/반려 후**: 선수 변경 불가 (반려 시 새 영상 업로드만 가능)
- **운영진과 대화** (1:1 메시지)
- 헤더에 통합 알림 표시 (신규 공지/신규 메시지 카운트)

### 4-3. 관리자 영역
- **영상 검수**: 회차별 업로드 영상 목록 + 상태 필터, 영상 재생, `승인 / 반려(사유 입력)`, 검수 화면에서 해당 선수에게 메시지 바로가기
- **선수 계정 관리**: 등록 / 일괄 등록 / 비밀번호 초기화
- **회차 순위 관리** (명예의 전당 노출)
- **공지사항 관리**: 작성/수정/삭제, 공개 범위·상단 고정 설정
- **통합 상담함**: 선수별 대화방 정렬·응대

## 5. 데이터 모델 (개략)
- **Player**: id, name, player_number, login_id, password_hash, phone, created_at
- **Admin**: id, login_id, password_hash
- **Round**: id, name(1전/2전/3전/결승), is_active
- **Video**: id, player_id, round_id, file_url, status(pending/approved/rejected), reject_reason, uploaded_at, reviewed_at, reviewer_id
- **Ranking**: id, round_id, player_id, rank, score(대회 룰에 따른 지표)
- **ViewerSession**: id, phone, verified_at, expires_at
- **Notice**: id, title, body, visibility(`all` / `player_only`), is_pinned, attachments, created_at, author_id
- **NoticeRead**: notice_id, user_id, read_at
- **ChatRoom**: id, player_id, status(open/closed), last_message_at, created_at  *(선수당 1개)*
- **ChatMessage**: id, room_id, sender_id, sender_role(admin/player), body, attachments, read_at, created_at

## 6. 비기능 요구사항
- **영상 제한**: 1개당 최대 **1GB / 15분**, 포맷 mp4·mov 등
- **모바일 우선** 반응형 (현장 업로드 비중이 높음)
- 업로드 진행률 표시, 실패 시 재시도 / 이어올리기
- 영상 저장소 및 인프라 구성: **개발자 제안 후 결정** (1GB 파일이 수십~수백 개 누적될 수 있으므로 트래픽/비용 고려 필요)

## 7. 외부 연동
- **낚시의맛 회원 조회 API**
  - 입력: 휴대폰 번호
  - 출력: 회원 여부 (필요 시 회원명 등 최소 정보)
  - 인증 키 / 엔드포인트는 낚맛 팀과 별도 협의

## 8. 부가 기능

### 8-1. 공지사항
- 관리자 작성/수정/삭제
- 공지별 공개 범위 설정
  - `전체 공개`: 낚맛 회원 시청자 + 선수 모두에게 노출 (메인 상단)
  - `선수 전용`: 로그인한 선수에게만 노출 (대시보드 상단)
- 상단 고정(pin), 안 읽음 뱃지, 이미지 첨부

### 8-2. 운영진과 대화 (1:1 메시지)
- **이용 대상**: 선수 로그인자만
- **구조**: 선수 ↔ 관리자 단일 통합 채널, **선수당 대화방 1개**
- **양방향 시작 가능**
  - 관리자 → 선수: 영상 반려 사유 보충, 자료 요청, 개별 안내 등
  - 선수 → 관리자: 문의·질문 (별도의 "고객상담" 메뉴 없음, 본 채널로 일원화)
- 실시간 메시지 + 오프라인 누적 (양쪽 접속 시 채팅처럼, 한쪽만 있을 때는 메시지가 쌓였다가 다음 접속 시 확인)
- 자체 구현, 사이트 내장 (외부 솔루션 미사용)
- 이미지 등 첨부 지원
- 관리자 부재 시간(운영시간 외) 자동 응답 메시지 설정 가능
- 영상 검수 화면에서 "이 선수에게 메시지" 바로가기 → 같은 대화방에 누적

### 8-3. 통합 알림
- 공지 / 메시지 등을 사이트 내 알림 시스템으로 통합 표시 (헤더 종 아이콘 + 카운트)

## 9. 향후 확장 고려
- 2전·3전·결승 진행 시 회차만 추가하면 동일 구조 재사용
- 전 회차 종합 명예의 전당 통합 뷰
- 영상 신고 / 부정행위 제보 기능

## 10. 개발자 위임 사항 (개발자 제안 → 운영팀 확정)
- 영상 저장소 선택 (R2 / S3 / 국내 클라우드 등)
- 업로드 방식 (Multipart, presigned URL, 이어올리기 등)
- 낚맛 회원 인증 세션 만료 기간
- 명예의 전당 순위 입력 방식 (수동 입력 / 승인 영상 계측값 자동 산출 / 외부 파일 업로드 등)
- 인프라/배포 환경 (기존 워커·Cloud Run 확장 vs 신규 구성)
- 채팅 실시간 통신 방식 (WebSocket / SSE / 폴링)
- 첨부 파일(공지·메시지) 용량/포맷 제한 제안
- 알림 채널 (사이트 내 뱃지 / 브라우저 푸시 / 이메일 / SMS)

## 11. 일정 (참고)
- 1주차: 인증(선수 로그인 + 낚맛 API 연동 + 시청 세션) + 마이페이지
- 2주차: 업로드 페이지 + 관리자 검수 + 공지사항
- 3주차: 명예의 전당 공개 페이지 + 운영진과 대화(1:1 메시지) + QA

## 부록 A. 확정된 정책 요약
- 동명이인 처리: 아이디에 선수번호 부착 (`이름012`)
- 시청 권한: 낚시의맛 앱 회원 (휴대폰 번호로 API 조회, 세션 유지)
- 시청자 본인 확인 강도: 휴대폰 번호 입력만 (SMS 인증 없음)
- 영상 용량: 최대 1GB / 15분
- 검수 대기 영상: 선수가 삭제·재업로드 가능 / 승인·반려 후에는 불가
- 낚맛 DB 연동: 낚맛 팀 제공 API 호출
- 공지: 공지별 공개 범위 설정 (전체 공개 / 선수 전용)
- 선수 간 쪽지: 제공하지 않음
- 채팅(1:1 메시지): 자체 구현, 사이트 내장, 선수 로그인자만 이용
- 쪽지 / 고객상담 메뉴 분리하지 않고 "운영진과 대화" 단일 채널로 통합
